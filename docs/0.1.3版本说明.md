# Apex SSH v0.1.3 更新说明

状态：待发布。

## 新增

- 首页支持选择 SSH 或 SFTP。选择 SFTP 后，连接成功即可打开文件面板。
- 首页支持搜索主机名称、说明、地址和用户名；输入未保存的连接地址时，可进入配置并自动填入地址和用户名。

## 修复与调整

- 调整设置页面布局、滚动和窄窗口显示，修复按钮、开关及操作反馈。
- 补齐紧凑模式、界面动画、传输进度等偏好的即时生效和保存，调整下载目录选项并兼容旧配置。
- 调整同步状态和已同步主机数量的显示，修复同步本地路径私钥时未正确读取文件的问题。
- 修复独立会话窗口的监控入口，支持暂停、继续及网卡选择，监控与 SFTP 面板可相互切换；修复后台监控自动启动后未持续采集的问题。
- 统一应用、窗口、首页和安装包的白底黑色终端图标，打包时自动生成图标资源。
- 字体随应用本地打包，更新首页截图及功能说明。
- 更新 Electron 和相关依赖，修复依赖审计报告的问题及旧版文件匹配依赖的兼容问题。

## 安装与更新

- 应用内更新目前仅支持 Windows 安装版；macOS 和 Linux 请下载安装包更新。
- 签名、公证及系统首次运行提示以最终发布产物核验结果为准。当前本地 Windows 试用包未签名。

发布时保留自动生成的八个安装包下载链接、Windows 更新元数据及完整变更记录。正式发布前仍需通过最终候选的远端安全检查、三平台构建和目标设备安装升级验收。

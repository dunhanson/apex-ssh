# 开发指南

本文档面向参与 Apex SSH 开发和验证的贡献者。产品功能与下载入口见项目根目录的 [README](../README.md)。

## 技术栈

- 桌面与渲染：Electron、React、TypeScript
- 终端与连接：xterm.js、ssh2
- UI 组件：shadcn/ui
- UI 基础：Radix UI、Tailwind CSS、Lucide

shadcn/ui 组件源码位于 `src/renderer/src/components/ui/`，配置见 `components.json`。视觉令牌以项目设计稿为准，不直接使用组件库默认主题。

## 环境要求

- Node.js 24
- pnpm 11.17.0
- 需要验证真实 SSH/SFTP 链路时安装 Docker

## 启动开发环境

```bash
pnpm install
pnpm dev
```

Windows 环境若存在 `ELECTRON_RUN_AS_NODE=1`，Electron 会以纯 Node 模式运行。启动前应移除该环境变量：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
pnpm dev
```

## 本地 SSH 验证环境

仓库提供两个 Docker SSH 容器，分别覆盖密码认证和密钥认证。

```bash
# Windows 首次运行时生成测试密钥
powershell -File deploy/生成密钥.ps1

docker compose -f deploy/docker-compose.yml up -d

# 首次运行时准备 SFTP 测试数据
sh deploy/准备测试数据.sh apex-ssh-pass
sh deploy/准备测试数据.sh apex-ssh-key
```

连接参数：

- 密码认证：`127.0.0.1:2222`，用户名 `apex`，密码 `apex123`
- 密钥认证：`127.0.0.1:2223`，用户名 `apex`，私钥 `deploy/keys/id_ed25519`

## 自动化验收

应用带远程调试端口启动后，可执行针对真实容器的 CDP 验收脚本：

```bash
pnpm dev -- --remote-debugging-port=9222

node scripts/验收M1.mjs
node scripts/验收交互.mjs
node scripts/验收HomeEnd.mjs
```

- `验收M1.mjs`：连接、彩色输出、多标签、错误提示和持久化等核心链路
- `验收交互.mjs`：vim 编辑保存、方向键历史和 Tab 补全
- `验收HomeEnd.mjs`：Home / End 行首行尾行为

## 目录结构

```text
apex-ssh/
├── deploy/       # 本地 Docker SSH 验证环境
├── docs/         # 开发与发布文档
├── resources/    # 应用图标等打包资源
├── scripts/      # 自动化验收与资源生成脚本
└── src/          # Electron 主进程、预加载脚本与 React 渲染层
```
